Консольная игра на Java: волшебник должен добраться до замка на поле 5×5, побеждая монстров решением математических задач, имея 3 жизни.

## Обозначения на поле

| Символ | Значение |
|---|---|
| `P` | Персонаж |
| `M` | Обычный монстр |
| `B` | Большой монстр |
| `C` | Замок |
| `.` | Пустая клетка |

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Открыть `Main.java`.
3. Нажать зелёный ▶ рядом с `main`.
